# Product Name

**Product Name:** Engram
**Repository Slug:** `engram`
**Tagline:** Spaced repetition that leaves a trace.

The name is original: an *engram* is the physical trace a memory leaves in
the brain — exactly what active recall builds. It was chosen to be distinct
from any existing product name in the spaced-repetition space.

## Usage rules

- The binary, crate and package name is `engram`.
- User-visible strings say **Engram** (no "app" suffix in the title bar).
- The project file extension is `.engram.json`.
