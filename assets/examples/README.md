# Engram Sample Library

`sample.engram.json` is a ready-to-open library that ships with every Engram
release. Open it in Engram via **File → Open Library** to exercise most
features without creating cards from scratch.

## What's inside

| Area | Contents |
| --- | --- |
| **Deck tree** | `General` with child decks `Science` and `Languages`; `Science` has per-deck daily-limit overrides. |
| **Card types** | Basic cards and a Cloze card (`{{c1::heart}}` / `{{c2::four}}`). |
| **Phases** | Review, Learning and New cards so queue ordering, limits and cram all have something to serve. |
| **Tags** | biology, cell, anatomy, geography, physics, french — try the tag filters. |
| **Suspend / bury** | One card is suspended; one is buried until November 2026. |
| **History** | Review logs start empty so you can record your own reviews and watch the stats page fill in. |

Try these workflows:

1. **Study queue** — open the library, start a session, and grade cards 1–4.
2. **Queue ordering** — toggle between Due first, Interleaved and Shuffled in Settings.
3. **Daily limits** — notice `Science` caps new cards at 10/day and reviews at 50/day.
4. **Suspend / bury** — open the card editor and toggle suspend or set a bury date.
5. **Cram** — start a cram session; it ignores due dates and daily limits.
6. **History** — record a few reviews, then open the per-card history window from the deck table.

The sample data is self-contained and safe to edit — changes only affect your
local copy of this file.
